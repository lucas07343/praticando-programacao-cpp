# 🧩 Praticando Programação em C++

Repositório dedicado à prática de C++ por meio de exercícios e testes de lógica. Aqui são trabalhadas as principais estruturas da linguagem:

- Estruturas sequenciais  
- Estruturas condicionais  
- Estruturas repetitivas  
- Vetores  
- Matrizes  

O objetivo é evoluir na linguagem de forma prática e consistente, resolvendo problemas reais e revisando conceitos fundamentais.
